|---|---|---|

## 1. 产品概述

### 1.1 定位
一款「以天为单位」的私人多媒体日记本，帮助用户随手记录文字、图片、录音、视频与手绘，并通过「历史今天」和 AI 助手让过去的记录持续产生价值。

### 1.2 目标用户
- 有长期记录习惯的手账/日记用户
- 重视隐私、希望数据掌握在自己手里的用户
- 有大量历史日记（含 PDF）需要归档整理的用户

### 1.3 核心价值
1. **好写**：随手记录，多媒体一键插入，自动补全天气/位置等上下文。
2. **好回看**：多视图浏览 + 历史今天 + 强搜索。
3. **私密可控**：本地优先，端到端加密，App 锁。
4. **会思考**：AI 助手可对话检索、心情洞察、活动推荐。

### 1.4 平台范围
- **一期：Android**（minSdk 24 / Android 7.0，targetSdk 最新）
- **二期：iOS**（复用 Flutter 业务代码，替换平台通道实现）

## 3. 功能详细设计

### 3.1 写日记（编辑器）

参考截图 1、2 的编辑器形态。

**页面结构**
- 顶部栏：`✕ 关闭` ｜ `日期 / 时间 周几 今天`（可点选改日期，支持补记过去某天）｜ `书签收藏` ｜ `⋮ 更多`（删除、导出本篇、移动日期等）
- 正文：富文本编辑区，占位「记录今日」
- 内联媒体：图片/视频/录音/手绘以内容块形式嵌入正文流
- 底部元数据区：`天气(多云·31℃)`、`位置(星河天地1期)`、`设备(OPPO Find X9 Pro)`、`字数统计`
- 底部工具条：`格式/主题` `#标签` `撤销` `列表` `缩进` `计时/番茄` `日历` 等
- 「+」插入：弹出底部面板，6 项——**相机、图库、视频、录音、心情、画板**

**内容模型（块结构）**

日记正文采用「块（Block）」结构，便于富文本 + 多媒体混排、导入导出与 AI 解析：

| 块类型 | 说明 |
|---|---|
| paragraph | 段落文本（支持加粗/斜体/下划线/删除线/字号/颜色） |
| heading | 标题 |
| bullet / ordered / todo | 无序/有序/清单列表 |
| quote / divider | 引用 / 分割线 |
| image | 图片（含缩略图、原图、说明、EXIF） |
| audio | 录音（时长、波形、转写文本可选） |
| video | 视频（时长、封面帧） |
| sketch | 手绘（矢量笔迹 + 位图快照） |

技术上以 **Quill Delta（flutter_quill）+ 自定义 Embed** 实现音频/视频/手绘嵌入，或采用自定义块 JSON；两方案在原型阶段二选一，推荐 Delta（生态成熟）。

**媒体处理**
- **图片**：`image_picker`/`camera` 采集 → 压缩（长边 ≤ 2048，质量 85）→ 生成缩略图 → 存 App 私有目录；查看支持缩放、左右滑动、保存到相册。
- **录音**：`record` 内置录音（AAC/.m4a），实时波形；播放用 `just_audio`，支持进度条、倍速；可选调用 AI 转写为文字。
- **视频**：拍摄或相册选择 → `video_compress` 压缩 → 生成封面帧；播放用 `video_player`，支持全屏。
- **手绘**：Canvas 画板（笔刷/颜色/橡皮/撤销），保存矢量笔迹 + PNG 快照。
- 所有媒体 **原文件存本地私有目录**，DB 仅存相对路径与元数据；开启云同步后再加密上传。

**上下文自动采集**
- 天气：根据定位调用天气 API（可缓存/可关闭）。
- 位置：GPS/网络定位 → 逆地理编码为地名（可手动改，可关闭）。
- 设备：读取机型。
- 时间：默认当前，可修改。
- 心情：从心情面板选择（emoji + 标签）。

**其它**
- **自动保存草稿**：编辑中定时 + 退出即存，防丢失。
- **一天多篇**：支持同一天写多篇，时间线内按时间聚合在该日下。
- **收藏/书签**：单篇可标记，供「书签」视图筛选。

参考截图 3、4 的首页与抽屉。

**3.2.1 浏览视图（多种显示方式）**

| 视图 | 说明 |
|---|---|
| **时间线**（默认） | 按天倒序，左侧大号「日 + 周几」，右侧卡片显示正文摘要、时间·天气·位置、缩略图。顶部「历史今天」卡片轮播 + 「共 N 篇」计数。 |

| 地图 | 按位置聚合，在地图上查看足迹。 |
| 分类（标签） | 按标签/本子分类浏览。 |
| 漫步 | 随机翻到一篇旧日记（偶遇式回顾）。 |

**3.2.2 历史今天（On this day）**
- 首页顶部轮播「N 年/月前的今天」，卡片展示当年该日的图文摘要。
- 支持推送提醒（可配置）。
- 作为 AI「活动推荐」的输入之一。

**3.2.3 搜索**
- **关键词搜索**：全文 + 标签 + 位置 + 天气（本地 FTS 索引）。
- **语义搜索**：本地向量检索（见 §6 AI），支持自然语言（"上次去海边"）。
- 结果高亮、按时间/相关度排序。

**3.2.4 回收站**
- 删除的日记进入回收站，保留 N 天（默认 30）后彻底清除；期间可恢复。

**3.2.5 导入 / 导出**

*导出：*
| 格式 | 内容 | 用途 |
|---|---|---|
| **应用备份包（.zip）** | 全量 JSON + 媒体文件 + 清单，可选加密 | 换机迁移 / 完整备份（无损） |
| **PDF** | 排版渲染（图文），可选时间范围 | 打印 / 归档 / 分享 |
| **Markdown** | 纯文本 + 图片引用 | 迁移到其它工具 |

*导入：*
| 来源 | 处理 |
|---|---|
| 应用备份包 | 直接还原（校验版本兼容） |
| **PDF（历史日记）** | 见下方「PDF 导入向导」 |
| Markdown | 解析为日记条目 |

**PDF 导入向导（重点需求）**

历史日记为 PDF，需支持导入。流程：

1. 选择 PDF 文件。
2. **文本层检测**：
   - 有文本层（数字版）→ 直接提取文字 + 内嵌图片。
   - 无文本层（扫描件）→ **OCR**（`google_mlkit_text_recognition` 端上识别，支持中英）。
3. **切分策略**（用户可选/AI 辅助）：
   - 按日期标题切分（正则识别「2024年3月5日 / 2024-03-05」等）→ 每段映射为一篇日记；
   - 或按页切分（1 页 = 1 篇）；
   - 或整本导入为 1 篇。
4. **预览与确认**：列出识别出的条目及推断日期，用户可批量校正日期、合并/拆分。
5. 导入落库，原 PDF 可作为附件保留。

> 边界：扫描件 OCR 精度有限，向导提供「保留原图 + 可编辑文本」双轨，避免信息丢失。

## 5. 数据模型设计

本地数据库采用 **Drift（SQLite）**，媒体走文件系统，向量走本地向量索引。

### 5.1 核心表

**diary（日记）**
| 字段 | 类型 | 说明 |
|---|---|---|
| id | TEXT(uuid) | 主键 |
| entry_date | DATE | 归属日期（用于按天分组） |
| created_at / updated_at | DATETIME | 创建/更新时间 |
| title | TEXT | 标题（可空，可 AI 生成） |
| content | JSON | 块结构正文（Delta/Blocks） |
| plain_text | TEXT | 去格式纯文本（供 FTS/AI） |
| mood | TEXT | 心情标识 |
| weather | TEXT | 天气快照 |
| temperature | TEXT | 温度 |
| location_name | TEXT | 地名 |
| lat / lng | REAL | 坐标（可空） |
| device | TEXT | 设备型号 |
| word_count | INT | 字数 |
| is_favorite | BOOL | 收藏 |
| is_deleted | BOOL | 软删除（回收站） |
| deleted_at | DATETIME | 删除时间 |
| notebook_id | TEXT | 所属本子/分类（可空） |
| sync_rev | INT | 同步版本号 |

**media_asset（媒体）**
| 字段 | 类型 | 说明 |
|---|---|---|
| id | TEXT | 主键 |
| diary_id | TEXT | 外键 |
| type | ENUM | image/audio/video/sketch/pdf |
| local_path | TEXT | 本地相对路径 |
| thumb_path | TEXT | 缩略图/封面 |
| cloud_key | TEXT | 云端对象键（加密后） |
| duration | INT | 时长（音视频，ms） |
| width/height | INT | 尺寸 |
| size | INT | 字节 |
| caption | TEXT | 说明 |
| transcript | TEXT | 语音转写（可空） |
| order_index | INT | 在正文中的顺序 |

**tag / diary_tag**：标签及关联表。
**notebook**：本子/分类。
**embedding**：`diary_id`、`chunk_id`、`vector(BLOB)`、`model`、`updated_at`（本地语义检索）。
**setting / profile**：键值设置与用户档案。
**sync_state**：同步游标、设备 ID、冲突记录。

### 5.2 全文检索
- 基于 SQLite **FTS5** 对 `plain_text`、`title`、`location_name`、标签建索引。

### 5.3 派生数据（不落库）
- 历史今天：按 `entry_date` 的「月-日」查询即可。
- 统计：聚合查询。

## 6. 技术架构

### 6.1 客户端（Flutter）

**分层（Clean Architecture）**
```
presentation  ── Widgets + 状态管理（Riverpod）
      │
domain        ── 实体 / UseCase / 仓储接口
      │
data          ── Repository 实现
                 ├─ local:  Drift(SQLite) + 文件存储 + 向量索引
                 └─ remote: 同步网关 / AI 网关（HTTPS）
platform      ── 平台通道：相机/录音/定位/天气/生物识别
```

**核心依赖（建议）**
| 领域 | 库 |
|---|---|
| 状态管理 | `riverpod` / `flutter_riverpod` |
| 本地 DB | `drift`（SQLite，支持迁移、FTS） |
| 数据库加密 | `sqlcipher`（SQLCipher）|
| 富文本 | `flutter_quill` |
| 图片 | `image_picker` `camera` `flutter_image_compress` |
| 录音/播放 | `record` `just_audio` |
| 视频 | `video_player` `video_compress` |
| 手绘 | 自研 CustomPainter 画板 |
| 定位/逆地理 | `geolocator` `geocoding` |
| 生物识别 | `local_auth` |
| PDF 导出 | `pdf` `printing` |
| PDF 解析 | `syncfusion_flutter_pdf` / `pdfx` |
| OCR | `google_mlkit_text_recognition` |
| 向量检索 | `sqlite-vec` / `objectbox` 向量索引 |
| 网络 | `dio` |

### 6.2 后端（仅服务同步 + AI，不存明文内容）

采用轻量 **BFF（Backend for Frontend）**，两大职责：

1. **AI 网关**：代理调用 Claude API（密钥仅存服务端，绝不下发到客户端）；负责鉴权、限流、脱敏校验、审计。
2. **同步服务**：存储**端到端加密后的**日记密文与媒体密文（服务端无法解密）；提供增量同步与冲突检测。

技术栈建议：Node.js（NestJS）或 Go；对象存储（S3 兼容）存加密媒体；PostgreSQL 存加密元数据与同步游标。

> 纯本地模式下（用户未开启云同步且未开启 AI），App 完全离线可用，无需后端。

### 6.3 同步机制

- **本地优先**：所有写操作先落本地，异步同步。
- **端到端加密（E2EE）**：以用户口令派生密钥（Argon2id）→ 加密内容后再上传；服务端零知识。
- **冲突解决**：字段级 Last-Write-Wins + 版本号（`sync_rev`）+ 墓碑（tombstone）处理删除；冲突不可自动合并时保留双版本并提示。
- **媒体同步**：分块上传/断点续传，弱网友好。

## 7. AI 能力详细设计

### 7.1 总体架构（RAG + 工具调用）

```
用户提问
  │
① 本地语义检索（Embedding + 向量库）→ 召回相关日记片段
  │
② 数据脱敏/最小化（按隐私级别裁剪）
  │
③ AI 网关 → Claude API（携带召回片段 + 指令）
  │
④ 返回回答 + 引用来源（可点击跳转到对应日记）
```

- **Embedding 生成**：联网时经 AI 网关调用向量化，向量**存本地**；检索在**本地**完成，仅把「召回到的最小片段」上云做回答，最大限度减少上云数据。
- **来源可追溯**：AI 回答附带引用的日记链接，避免臆造。

### 7.2 具体能力

**① 日记助手（对话检索）**
- 例："我上个月去海边是哪天？" → 语义检索 → "7 月 12 日，你在青岛…" + 跳转卡片。
- 支持追问、多轮、条件过滤（时间/地点/标签/心情）。

**② 心情分析与陪伴**
- 输入：当天 / 近 7 天日记（文本 + 心情标注）。
- 输出：心情概览、趋势、温和的陪伴式对话；识别到明显低落时给出关怀话术与（可选）求助资源，不做医疗诊断。

**③ 历史今天 + 活动推荐**
- 输入：历史今天集合 + 当日天气/位置/日程上下文。
- 输出："去年今天你去了野餐，今天天气也不错，附近有 XX，要不要…" 类的活动推荐。

**④ 写作辅助**
- 起题灵感、续写、把零散记录整理成当日总结、扩写/润色。

**⑤ 自动标注**
- 保存日记时（可选）自动打标签、推断心情、生成标题与摘要。

**⑥ 周/月回顾**
- 生成时间段回顾长文与亮点集锦，可推送。

### 7.3 交互入口
- 抽屉「AI 助手」独立对话页。
- 首页顶部「问助手」轻量入口。
- 编辑器内「AI 辅助」（续写/总结/润色）。
- 设置内「AI 周报」开关。

### 7.4 隐私与可控（关键）
- **总开关**：AI 默认可关闭，关闭后一切内容不出设备。
- **隐私级别**：
  - 严格：仅上传用户当次明确选择的片段；
  - 平衡（默认）：上传语义召回的最小相关片段；
  - 全量：允许更大上下文（更好效果，用户显式同意）。
- **脱敏**：可选对人名、电话、地址等做本地脱敏后再上云。
- **不训练**：调用方声明数据不用于模型训练；透明告知数据流向。
- **审计与清除**：可查看/清除 AI 交互缓存。

## 8. 隐私与安全

| 层面 | 措施 |
|---|---|
| 传输 | 全链路 HTTPS/TLS；证书校验 |
| 存储 | SQLCipher 加密 DB；媒体可选加密；密钥存 Android Keystore |
| 应用锁 | PIN + 生物识别（`local_auth`），后台马赛克/隐藏 |
| 云端 | 端到端加密，服务端零知识；对象存储仅存密文 |
| AI | 见 §7.4，最小化 + 脱敏 + 可关 |
| 权限 | 相机/麦克风/定位/存储按需申请，均可拒绝且降级可用 |
| 合规 | 隐私政策、用户协议、数据导出与账号注销（数据可删除权） |
