手机日记本 App · 详细设计文档

以「天」为单位的私人多媒体日记本 —— 随手记录文字 / 图片 / 录音 / 视频 / 手绘，本地优先、端到端加密，并以「历史今天」与 AI 助手让过去的记录持续产生价值。

v0.1 评审稿 2026-08-16 Flutter 本地优先 + 可选云同步 云端大模型 (Claude) 一期 Android
✦

已确认选型：客户端 Flutter（一套代码覆盖安卓/iOS）· 存储 本地优先 + 可选端到端加密云同步 · AI 云端大模型 API（配套脱敏、显式授权、本地向量检索）。三项均为推荐方案。参考 App 沿用「本地手账 + 历史今天」范式，本设计在其上叠加 AI 能力、PDF 导入、E2EE 云同步 三大差异化。

01产品概述

定位与目标用户

一款「以天为单位」的私人多媒体日记本，服务于有长期记录习惯的手账/日记用户、重视隐私希望数据自己掌握的用户，以及有大量历史日记（含 PDF）需要归档整理的用户。

核心价值

好写

随手记录，多媒体一键插入，自动补全天气 / 位置 / 设备 / 字数等上下文。

好回看

时间线 / 日历 / 图库 / 地图 / 分类 / 漫步多视图，加历史今天与强搜索。

私密可控

本地优先、端到端加密、App 锁；AI 可关、可脱敏、数据流向透明。

会思考

AI 助手对话检索、心情洞察与陪伴、结合历史今天的活动推荐。

03功能详细设计

3.1 写日记（编辑器）

沿用参考 App 的编辑器形态：顶部「日期 / 时间 周几 今天」+ 书签收藏 + 更多菜单；正文占位「记录今日」；正文下方自动带 天气(多云·31℃)、位置(星河天地1期)、设备(OPPO Find X9 Pro)、字数统计；底部工具条含 标签(#)、撤销、列表、缩进、计时、日历等；「+」插入弹出底部面板六项。

📷 相机 / 图库

拍摄或选图，压缩存本地，生成缩略图，查看支持缩放滑动。

🎬 视频

拍摄或相册，压缩 + 封面帧，内置播放全屏。

🎙 录音

内置录音 + 实时波形，倍速播放，可选 AI 转写。

🙂 心情

emoji + 标签，进入统计与 AI 心情分析。

🖌 画板（手绘）

笔刷/颜色/橡皮，存矢量笔迹 + PNG 快照。

🏷 上下文

天气 / 位置 / 设备 / 时间自动采集，均可改可关。

内容模型（块结构）

正文采用「块（Block）」结构，便于富文本 + 多媒体混排、导入导出与 AI 解析。技术上以 flutter_quill（Delta）+ 自定义 Embed 实现音视频/手绘嵌入（推荐），原型阶段定稿。

块类型说明
paragraph / heading段落、标题，支持加粗/斜体/下划线/字号/颜色
bullet / ordered / todo无序 / 有序 / 清单列表
quote / divider引用 / 分割线
image缩略图 + 原图 + 说明 + EXIF
audio时长 + 波形 + 可选转写
video时长 + 封面帧
sketch矢量笔迹 + 位图快照

其它：自动保存草稿（编辑中定时 + 退出即存）· 一天多篇（时间线内聚合到该日下）· 收藏/书签。所有媒体原文件存 App 私有目录，DB 仅存相对路径与元数据。

浏览视图（多种显示方式）

视图说明
时间线（默认）按天倒序，左侧大号「日 + 周几」，右侧卡片显示摘要、时间·天气·位置、缩略图；顶部历史今天轮播 + 「共 N 篇」计数

历史今天 · 搜索 · 回收站

  • 历史今天：首页顶部轮播「N 年/月前的今天」，可推送提醒，作为 AI 活动推荐输入。
  • 搜索：关键词全文（本地 FTS5）+ 语义检索（本地向量），支持自然语言，结果高亮排序。
  • 回收站：删除进回收站保留 30 天可恢复，之后彻底清除。

📄

PDF 导入向导（重点需求） —— 历史日记为 PDF，支持数字版与扫描件两轨导入。

1
选择 PDF 文件
2
文本层检测有文本层直接提取文字 + 内嵌图片；扫描件走端上 OCR（ml_kit，中英）
3
切分策略按日期标题切分（正则识别日期）/ 按页切分 / 整本为一篇，AI 可辅助
4
预览与确认列出识别条目及推断日期，批量校正、合并/拆分
5
落库导入日记，原 PDF 可作附件保留；扫描件采用「原图 + 可编辑文本」双轨兜底

05数据模型设计

本地数据库采用 Drift（SQLite），媒体走文件系统，向量走本地向量索引，全文用 FTS5。

diary（日记）核心字段

字段类型说明
idTEXT(uuid)主键
entry_dateDATE归属日期（按天分组）
created_at / updated_atDATETIME创建 / 更新时间
titleTEXT标题（可空，可 AI 生成）
contentJSON块结构正文（Delta/Blocks）
plain_textTEXT去格式纯文本（供 FTS/AI）
mood / weather / temperatureTEXT心情 / 天气 / 温度快照
location_name / lat / lngTEXT/REAL地名与坐标（可空）
device / word_countTEXT/INT设备型号 / 字数
is_favorite / is_deleted / deleted_atBOOL/DATETIME收藏 / 软删除（回收站）
notebook_id / sync_revTEXT/INT所属本子 / 同步版本号

其它表

  • media_asset：type(image/audio/video/sketch/pdf)、local_path、thumb_path、cloud_key、duration、尺寸、caption、transcript、order_index
  • tag / diary_tag / notebook：标签、关联、本子分类
  • embedding：diary_id、chunk_id、vector(BLOB)、model —— 本地语义检索
  • setting / profile / sync_state：设置、档案、同步游标与冲突记录

6.2 后端（仅同步 + AI，不存明文）

AI 网关

代理调用 Claude API，密钥仅存服务端；负责鉴权、限流、脱敏校验、审计。

同步服务

只存端到端加密后的密文，服务端零知识；提供增量同步与冲突检测。

◉

纯本地模式下（未开云同步且未开 AI），App 完全离线可用，无需后端。技术栈建议 NestJS/Go + S3 兼容对象存储 + PostgreSQL。

6.3 同步机制

  • 本地优先：写操作先落本地，异步同步。
  • 端到端加密：用户口令派生密钥（Argon2id）→ 加密后上传，服务端零知识。
  • 冲突解决：字段级 Last-Write-Wins + 版本号(sync_rev) + 墓碑处理删除；不可自动合并时保留双版本。
  • 媒体同步：分块上传 / 断点续传，弱网友好。

07AI 能力详细设计

7.1 总体架构（RAG）

1
本地语义检索Embedding + 向量库，召回相关日记片段（在本地完成）
2
数据脱敏 / 最小化按隐私级别裁剪，只带最小相关片段
3
AI 网关 → Claude API携带召回片段 + 指令
4
回答 + 引用来源附可点击的日记链接，可追溯、防臆造
🔒

Embedding 联网时经网关生成、向量存本地，检索在本地，仅把召回到的最小片段上云做回答 —— 最大限度减少上云数据。

7.2 具体能力

日记助手（对话检索）

「上个月去海边是哪天？」→ 语义检索 → 定位到 7/12 并附跳转卡片；支持多轮追问与条件过滤。

心情分析与陪伴

分析当天/近 7 天记录，给出心情概览与趋势、温和陪伴对话；识别低落给关怀，不做医疗诊断。

历史今天 + 活动推荐

结合历史今天与当下天气/位置，推荐今日活动。

写作辅助

起题、续写、把零散记录整理成当日总结、润色。

自动标注

保存时可选自动打标签、推断心情、生成标题摘要。

周 / 月回顾

生成时间段回顾长文与亮点集锦，可推送。

7.4 隐私与可控（关键）

隐私级别行为
严格仅上传用户当次明确选择的片段
平衡（默认）上传语义召回的最小相关片段
全量允许更大上下文（效果更好，需显式同意）

总开关默认可关，关闭后内容不出设备；可选本地脱敏人名/电话/地址；声明不用于训练；可查看/清除 AI 缓存。

08隐私与安全

层面措施
传输全链路 HTTPS/TLS + 证书校验
存储SQLCipher 加密 DB；媒体可选加密；密钥存 Android Keystore
应用锁PIN + 生物识别；后台马赛克/隐藏
云端端到端加密，服务端零知识，对象存储仅存密文
AI最小化 + 脱敏 + 可关（见 §7.4）
权限相机/麦克风/定位/存储按需申请，拒绝后降级可用
合规隐私政策、用户协议、数据导出与账号注销（可删除权）
